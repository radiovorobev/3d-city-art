# Улица Мира — интерактивная галерея

MVP интерактивной 3D-карты фрагмента улицы Мира у Австрийской площади. Дома выступают навигацией к серии художественных работ.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Данные геометрии получены из OpenStreetMap через Overpass API. При каждом push в ветку `main` проект автоматически публикуется на GitHub Pages.
